# I AM

Melitia Marie’s house. One site for the board, the booth, the wall, the school, and the wire.

The pocket you hear on the wall is the same pocket the studio plays. Follow someone and they stay in the room. Press a record and the house writes the sheet a distributor files.

## Run

```bash
npm install
npm run dev
```

Open the local address the dev server prints. The door is email and password. Credits, likes, and the board stay on this device until a database is connected.
